Design principles

written by humans

Values built
into the software.

Enliner is built on a set of values that permeate the product.

  1. 01

    Personal
    compute

    The transcription, the search, and the AI all run on the Mac in front of you, on models that live on the machine. Computation stays where you are, instead of on rented silicon you reach across the network. That is the whole point: the value of the work stays with the person doing it. Expect it to be rougher than a polished frontier lab's AI experience.

  2. 02

    Offline
    first

    Enliner works offline at full strength. All of its AI features work too. It won't be crippled when you want to synthesize on a train or take a voice memo in a remote cottage with intermittent internet.

  3. 03

    Portable
    data

    Enliner vaults are standard Markdown on disk, one file per page, and those files are the original your work lives in. The app keeps an internal database for speed, but it is only an index: delete the app and all the data stays there, in the same structure you created.

  4. 04

    Privacy
    first

    Enliner Relay is secure sync that moves sealed bytes, everything end-to-end encrypted to keys the members hold. You can run the relay yourself, in your own cloud or on your home network: any Raspberry Pi with an SSD will do. You can also encrypt the vault itself with standard algorithms that decode it outside Enliner.

  5. 05

    Perpetual
    ownership

    You pay a single price and the software is yours, with a year of updates included. After that, keep using everything forever, or choose to pay for updates when a feature excites you.

Why it's built this way

The argument
behind the principles.

These commitments come out of a bigger question about where computing should happen as the cloud moves to meter all of it. That is the philosophy behind the project.
